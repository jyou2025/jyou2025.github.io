个人简介

本人的研究方向主要包括大数据分析、机器学习、动态机理建模、统计建模及智能体应用，重点关注这些方法在动物生产和饲料加工领域的应用。研究工作涉及生物学与生产数据的整合分析、预测模型开发、动物生长与代谢过程的动态模拟，以及数据驱动的生产决策支持。通过结合数据分析、数学建模与人工智能技术，为提高动物生产效率、优化饲料加工过程及促进生产系统的可持续发展提供科学依据和技术支持。

数据整合 特征工程 缺失数据插补 异常检测 机器学习 动态机理模型 混合效应模型 荟萃分析 参数估计 智能体应用 Python SAS Julia R

代表性科研项目

火鸡生长与代谢的动态机理模型

本项目与 Hendrix Genetics 合作，旨在构建基于常微分方程的动态机理模型，模拟现代商业火鸡的生长发育及体内蛋白质和脂肪的动态代谢过程。目前，相关研究论文正在撰写中。

研究方法： 动态机理模型 参数估计 敏感性分析 Julia

颗粒饲料质量预测与优化（项目 1.0 与 2.0）

本项目与 Trouw Nutrition Canada（泰高动物营养加拿大）、Molesworth Feed Supply、MasterFeeds 和 Jones Feed Mills 等企业合作，利用机器学习和统计建模方法，研究饲料配方、加工工艺及环境因素对颗粒饲料耐久性指数（Pellet Durability Index，PDI）的影响，并开发 PDI 预测模型，为饲料厂的生产过程优化和质量管理提供技术支持。

研究方法： 数据整合 机器学习 混合效应模型 回归分析 特征工程 Python SAS

基于精准饲喂系统的肉种鸡生产数据机器学习研究

本项目基于精准饲喂系统采集的大规模肉种鸡生产数据，利用机器学习方法构建产蛋事件预测模型，并开发异常体重数据的自动识别与清理方法，以提高生产数据的质量和利用效率，为肉种鸡的精准饲养管理提供技术支持。

研究方法： 机器学习 分类模型 Python

科研软件与工具

1. irapy

基于 Python 开发的影响范围评估（Impact Range Assessment，IRA）软件库，支持单次及重复 IRA 分析，用于评估输入变量对回归模型预测结果的影响，提高模型的可解释性，并为敏感性分析提供工具支持。

可解释人工智能 机器学习 敏感性分析 模型可解释性 回归分析 Python

→ 查看 GitHub 仓库

2. PDI 在线预测工具

基于机器学习和统计建模方法，开发并部署交互式网页应用，实现商业饲料厂颗粒饲料耐久性指数（PDI）的在线预测，为饲料质量评估和生产工艺优化提供辅助决策支持。

模型部署 饲料加工 颗粒饲料质量 网页应用 Python

→ 打开工具

3. PDI Agent

本项目旨在开发基于大语言模型（LLM）的饲料厂预测模型自动化管理框架，将规则驱动的工作流程与智能体技术相结合，探索预测模型的自动化监测、性能评估与更新方法，为预测模型的长期运行和维护提供技术支持。

大语言模型（LLM） 智能体应用 模型更新 模型部署 饲料加工 颗粒饲料质量 Python

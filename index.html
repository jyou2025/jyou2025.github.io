About Me

My research focuses on big data analytics, machine learning, dynamic mechanistic modelling, statistical modelling, and AI agent applications, particularly in animal production and feed manufacturing. My work involves integrating and analyzing biological and production data, developing predictive models, simulating animal growth and metabolic processes, and supporting data-driven decision-making. By combining data analytics, mathematical modelling, and artificial intelligence, I aim to improve production efficiency, optimize feed manufacturing processes, and support the sustainability of animal production systems.

Selected Projects

Dynamic Mechanistic Model of Turkey Growth and Metabolism

Developing a compartmental ODE-based mechanistic model to simulate growth and metabolic processes, including protein and fat turnover, in modern commercial turkey genetic lines. Collaboration with Hendrix Genetics. Manuscript in preparation.

Methods: ODE-based Mechanistic Modelling Parameter Estimation Sensitivity Analysis Julia


Pelleted Feed Quality Prediction (Project 1.0 & Project 2.0)

Developed machine learning and statistical models to predict Pellet Durability Index (PDI). Integrated nutrition factors, manufacturing parameters, and environmental variables to built robust prediction systems to support real-time decision-making at the mill level. Collaborated with Trouw Nutrition Canada, Molesworth Feed Supply, MasterFeeds, and Jones Feed Mills.

Methods: Data Integration Machine Learning Mixed-Effects Models Regression Feature Engineering Python SAS


Machine Learning for Precision-Fed Broiler Breeder Production Data

This project applies machine learning to large-scale production data collected from precision-fed broiler breeders. The research focuses on predicting oviposition events and developing automated methods for detecting and cleaning anomalous body weight records, with the aim of improving data quality and supporting precision management of broiler breeders.

Methods: Machine Learning Classification Python

Research Software & Tools

1. irapy

A Python library for Impact Range Assessment (IRA), supporting both single and repeated analyses to quantify the influence of input variables on regression model predictions and improve model interpretability.

Explainable AI Machine Learning Sensitivity Analysis Model Interpretability Regression Python

2. PDI Prediction Web Tools

An interactive web application developed and deployed using machine learning and statistical modelling approaches to predict Pellet Durability Index (PDI) in commercial feed mills, supporting feed quality assessment and production process optimization.

Model Deployment Feed Manufacturing Pellet Quality Web App Python

→ Open Tool

3. PDI Agent

This project aims to develop a large language model (LLM)-based framework for automated management of predictive models in feed mills. By integrating rule-based workflows with AI agents, the framework explores automated model monitoring, performance evaluation, and updating to support long-term model maintenance.
